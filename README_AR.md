# لعبة تحديات DXN V30 — النسخة Online

هذه النسخة تنقل V30 من تخزين الهاتف إلى قاعدة بيانات مركزية عبر Supabase، مع الحفاظ على هوية الواجهة والشعار.

## ما تم تنفيذه
- دخول عضو برقم العضوية + PIN من أي جهاز.
- دخول قائد مستقل.
- قاعدة بيانات مركزية للأعضاء والفرق والتحديات والنجوم والإنجازات والأسئلة والتارجت.
- اعتماد الإنجاز من القائد قبل إضافة النجوم.
- التحديات لا تختفي بعد إنجازها؛ يمكن تكرارها حسب `repeat_rule`، مع منع الطلب المكرر المعلّق لنفس التحدي.
- 5 أسئلة شهرية ثابتة، وكل عضو يجيب عن كل سؤال مرة واحدة فقط خلال الشهر، ثم يظهر له جوابه ويغلق السؤال.
- الأسئلة تعطي ⭐1 فقط بعد اعتماد القائد.
- التارجت الشهري منفصل: القائد يسجل نقاط DXN الفعلية، وعند بلوغ 100 يمكن إضافة مكافأة ⭐100 مرة واحدة للشهر.
- ترتيب الفرق والمتصدرين والإحصائيات مركزية.
- PWA: يمكن إضافة الموقع إلى الشاشة الرئيسية في الهاتف.

## التشغيل
1. أنشئ مشروعاً جديداً في Supabase.
2. افتح SQL Editor والصق كامل `schema.sql` ثم Run.
3. افتح `config.js` وضع `SUPABASE_URL` و`SUPABASE_ANON_KEY` من Project Settings > API.
4. لا تضع `service_role` key في المتصفح.
5. ارفع المجلد إلى Vercel أو Netlify أو GitHub Pages.
6. افتح الرابط من الهاتف.

## إنشاء أعضاء
لإنشاء أول عضو تجريبي من SQL:

```sql
insert into public.members(member_no,name,team_id)
select '820426486','وائل سمير',id from public.teams where name='فريق القمة';
insert into public.app_users(login_no,pin_hash,role,member_id)
select '820426486',crypt('123456',gen_salt('bf')),'member',id from public.members where member_no='820426486';
```

ثم يدخل العضو من أي جهاز برقم العضوية `820426486` وPIN `123456`.
